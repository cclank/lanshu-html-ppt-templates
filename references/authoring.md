# 模板作者指南

## 文件和内容边界

`assets/templates/` 保存原始模板，`assets/thumbs/` 保存封面缩略图，`catalog.json` 是模板元数据和原始文件校验值。使用 `scripts/deck.py new` 将模板复制到用户输出目录，再修改副本。模板本身不需要 Python、Node、服务端或 API 密钥即可在浏览器播放。

模板包含样例品牌、公司、数据和来源署名。这些内容只用于理解版式；重新制作演示时使用用户材料和可核验来源，删除不适用的来源署名与联系方式。

## 不同引擎的修改位置

| 模板 | 页面或状态结构 | 修改注意事项 |
|---|---|---|
| 01–09、14、18 | `.stage` 中的 `.slide` | 保留播放内核，增删 section 后更新备注；图表可能位于内联脚本。 |
| 10 无限画布 | 地图上的 `.frame` 与镜头目标数组 | 页面是镜头位置，新增内容需一起调整位置、缩放和导航目标。 |
| 11 数据变形 | `.slide`、点数据、`LAY` 布局数组 | 每一页对应一套点阵目标；正文、图例和布局使用相同口径。 |
| 12 生成艺术 | `.slide`、生成器和随机种子 | 保留画布绘制循环；固定种子只能复现由该种子控制的部分。 |
| 13 电影片头 | `.shot` 和镜头配置 | 文字长度要适应镜头与时长，不能只增添普通 `.slide`。 |
| 15 动态排版 | `.slide` 与逐页动画 | 字数、字重和字宽是版式的一部分，检查新增中文的字体回退。 |
| 16 空间界面 | 三维面板、位置和镜头配置 | 修改面板内容时保留变换层级，检查视差、遮挡和导航。 |
| 17 终端 | `PAGES` 数组、输出和打字动画 | 更新命令字符串、输出结构、异步动画和备注；不会执行命令。 |
| 19 桌面拼贴 | 桌面物件与 `SL` 镜头数组 | 物件坐标、拖动状态和镜头目标共同决定构图。 |
| 20 地球仪 | `.slide`、地点/航线/镜头配置 | 经度纬度、地点标签和数据需对应；打印使用地球快照。 |

所有模板都包含 `script#deck-notes`。这里的 JSON 数组按放映顺序保存逐页讲稿，增删页面后需同步。浏览器标题与正文封面分别修改，`new --title` 只修改前者。

## 字体和阅读源码

每个 HTML 的 `style#embedded-fonts` 很大，包含 WOFF2 的 Base64 数据。用 `python3 scripts/deck.py source 07-consulting` 查看带原始行号的精简源码，避免把字体载入模型上下文。这个命令的结果仅供阅读。

中文字体只包含样例使用的字符，替换文本后会按 CSS 的字体栈回退。新增中文较多时可改用 `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`，重新检查换行和布局。字体裁剪需要完整字体源，单靠已裁剪的模板字体无法补回缺失字符。

修改时保留完整源文件中的内嵌字体，避免把精简显示中的占位符写回 HTML。缩略图在复制演示时可不携带，模板不依赖这些图片。

## 打印、演讲者和状态

13 套模板具有多页打印样式：01–09、14、15、18、20。使用浏览器打印到 PDF 时打开“背景图形”、边距选“无”，并检查分页、文字和图表。这是静态实现分类，不代表所有浏览器中的导出效果都已经验证。

10、11、12、13、16、17、19 缺少完整多页打印适配，优先在浏览器放映。10 的现有打印规则只隐藏操作栏。

S 键打开的演讲者窗口使用两个独立 iframe 展示当前页和下一页，页码经主窗口 hash 同步。这个机制不会自动同步实时财务参数、随机种子、拖拽物件位置等临时状态。不要把这些预览当成主屏实时截图。

各套都支持方向键、PageUp/PageDown 和点击翻页，实验模板另有自己的交互。O 键总览：01–09、14、15、18、20 使用自带总览，10 的 O 键回到总图，其余实验模板由放映工具包用缩略预览拼出总览。

## 放映工具包与手机遥控

每套模板在演讲者代码块之前有一段 `<!-- TOOLKIT v2 -->` 代码块，提供激光笔、画笔批注、黑白屏、页码跳转、总览补充、快捷键面板和手机遥控。它只通过 `#页码`、`window.deck.go()` 和键盘事件与各引擎协作，不依赖具体版式，改稿时原样保留。

- 源码是 `assets/toolkit.html`。修改后运行 `python3 scripts/inject_toolkit.py`：它会替换每套模板中的旧代码块，并让演讲者窗口转发 B/W 黑屏键。然后更新 `catalog.json` 的 sha256，并在浏览器中检查。
- 批注按页保存在内存里，刷新后清空，不会进入打印。总览缩略图和手机预览都是 `?presenter-preview` 独立实例；缩略图画完入场后会停止逐帧绘制。
- `scripts/present.py` 是只用标准库的 HTTP 服务，监听局域网地址。`/remote` 是手机遥控页；演示和手机凭 6 位配对码、经 Server-Sent Events 通信；二维码由脚本在本地生成，不访问外网。直接双击打开的模板没有遥控能力，按 M 只显示使用说明。

## 验证边界

`scripts/deck.py validate` 检查备注 JSON 和 JavaScript 语法，`scripts/check.py` 还会检查整个库的 20 套资源、页数、缩略图、校验值、放映工具包是否为最新版和网站链接。两者均不执行浏览器脚本。

实际交付前在可用浏览器检查最长内容、关键图表、首页、末页、导航和备注。需要 PDF 时检查导出文件。避免把语法通过描述成视觉验收通过。
