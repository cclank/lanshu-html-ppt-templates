手机遥控

在完整包目录运行本地放映服务，浏览器会自动打开模板列表；打开任意一套后按 M，用手机相机扫码，即可翻页、看逐页讲稿、跳页、黑屏，并在手机上使用激光笔和画笔。手机和电脑需要连同一个 Wi‑Fi。

python3 scripts/present.py
python3 scripts/present.py outputs/presentation.html

只需要 Python 3，不用安装依赖。服务运行期间，同一网络中的设备可以访问被放映的文件夹；按 Ctrl+C 停止。直接双击文件或在本站在线放映时，按 M 只会显示这段说明。

安装 Skill

解压完整包，进入 lanshu-html-ppt-templates 目录。已安装 Python 3.10+ 时，运行：

python3 scripts/install.py

安装器默认写入 ~/.codex/skills/lanshu-html-ppt-templates，会拒绝覆盖已有目录。其他支持 Skill 的工具可以指定自己的技能目录：

python3 scripts/install.py --skills-dir /path/to/your/skills

重新打开助手的新聊天后，使用下面的提示：

使用 $lanshu-html-ppt-templates，
把下面的内容做成 12 页产品发布演示。
受众是企业客户，采用暗夜极光风格，
输出单文件 HTML，并写好逐页演讲备注。

[粘贴你的内容]

手动选择和创建副本

python3 scripts/deck.py list
python3 scripts/deck.py list --pdf
python3 scripts/deck.py new 07-consulting \
  --output outputs/presentation.html \
  --title "年度业务战略"
python3 scripts/deck.py validate outputs/presentation.html

new 保留完整字体和播放内核，--title 仅修改浏览器标题。正文和备注需要继续改写。validate 进行静态检查，JavaScript 语法检查需要 Node.js。

PDF 与交互

01–09、14、15、18、20 共 13 套模板带有多页打印样式。打印到 PDF 时启用“背景图形”，边距选择“无”，并实际检查分页。首页可按这项能力筛选模板。

无限画布、数据变形、生成艺术、电影片头、空间界面、终端和桌面拼贴优先在浏览器放映，目前没有完整的多页打印适配。可编辑的 PowerPoint 文件需要额外转换。

实时模型的演讲者预览是独立实例，主屏调整参数后不会自动同步预览中的数值。新增中文可能使用系统字体回退，修改内容后应检查字体、换行和版面。
